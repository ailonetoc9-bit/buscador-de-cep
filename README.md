#  Buscador de CEP em Java

Um aplicativo desktop desenvolvido em Java que permite ao usuário digitar um CEP e obter automaticamente os dados completos do endereço (Rua, Bairro, Cidade, Estado) através do consumo de um Web Service.

##  Funcionalidades

- Interface gráfica amigável e intuitiva (GUI).
- Busca de dados de endereço em tempo real.
- Tratamento de erros (ex: CEP inválido ou não encontrado).
- Limpeza rápida dos campos para novas consultas.

##  Tecnologias e Ferramentas Utilizadas

- **Linguagem:** Java
- **IDE:** Eclipse
- **Interface Gráfica:** Java Swing (JFrame) utilizando o plugin WindowBuilder.
- **Integração:** Consumo de Web Service / API de CEP (formato JSON/XML).

##  Sobre o Projeto

Este projeto foi desenvolvido como forma de aprimorar os conhecimentos em programação orientada a objetos (POO), desenvolvimento de interfaces gráficas em Java e consumo de APIs externas. 
*Nota: O projeto foi construído acompanhando as aulas do Professor José de Assis.*
